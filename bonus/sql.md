# Проверка данных в БД

Так как прямой доступ к тестовой базе данных в рамках демо-стенда отсутствует, ниже представлена спроектированная бизнес-задача и эталонный SQL-запрос для верификации бронирований на стороне СУБД (PostgreSQL / MySQL).

---

## 📋 Постановка аналитической задачи

**Условие:** Выгрузить из базы данных список всех подтвержденных бронирований столика на ближайшие выходные дни — **субботу (05.09.2026)** и **воскресенье (06.09.2026)**, начиная **с 18:00 включительно** (пиковые часы работы ресторана).

**Требуемые поля в финальном отчете:**
- На чье имя забронировано
- Номер телефона гостя
- Время брони
- Количество гостей

---

## 💻 Эталонный SQL-запрос (Решение)

```sql
SELECT 
    name AS "На чье имя забронировано",
    phone AS "Телефон",
    time AS "Время брони",
    guests AS "Количество гостей"
FROM 
    bookings
WHERE 
    date IN ('2026-09-05', '2026-09-06')
    AND time >= '18:00'
ORDER BY 
    date ASC, 
    time ASC;

```
